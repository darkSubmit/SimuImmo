# Simulateur crédit immo & reste à vivre
 
- `index.html` : la page (aucune donnée personnelle, aucune dépendance). À publier sur GitHub Pages.
- `simulation-immo.json` : tes données, en deux objets : `simulation_credit` (onglet Capacité d'achat) et `reste_a_vivre` (onglet Reste à vivre). **À garder sur ton ordinateur, ne pas le déposer dans le dépôt.**
## Utilisation
Ouvre la page, clique sur « Charger un JSON » (ou glisse le fichier sur la page). Après modification, « Enregistrer en JSON » télécharge une nouvelle sauvegarde. Rien n'est envoyé ni stocké en ligne.
